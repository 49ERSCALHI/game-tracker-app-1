# Sideline Stat Tracker

This repository contains a small static single-file app (index.html) that tracks football stats by jersey number.

Quick start

1. Enable GitHub Pages in this repository:
   - Go to Settings → Pages
   - Under "Source" select **Branch: main** and **Folder: /** (root), then click Save
   - Wait ~1 minute and the Pages URL will appear. It will usually be:
     https://49ERSCALHI.github.io/game-tracker-app-1/

2. Open the Pages URL in a browser and share it with others.

Notes

- The app uses localStorage to save game state in the browser. Statistics are stored locally on each device.
- If you make changes to index.html, push them to the main branch and the Pages site will update shortly.
- If you want automatic deployments using a build step or different branch, let me know and I can add a workflow.
